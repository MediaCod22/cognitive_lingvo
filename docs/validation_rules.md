# Правила проверки качества корпуса

## 1. Проверка карточки

Каждая карточка проверяется по следующим критериям:

- заполнен text_id;
- есть заголовок;
- есть источник;
- есть дата публикации;
- есть URL;
- есть дата обращения;
- указан жанр;
- указан сегмент корпуса;
- указана тематическая зона;
- указано основание включения;
- заполнена разметка;
- количество элементов в каждой множественной категории не превышает 7.

## 2. Проверка баланса

Баланс проверяется по следующим уровням:

- сегмент корпуса;
- год;
- источник;
- тематическая зона;
- регион;
- жанр;
- слой скорости: быстрый, среднесрочный, долгий, глубинный.

## 3. Проверка дедубликации

Дубли исключаются, если:

- совпадает URL;
- совпадает заголовок;
- совпадает почти весь текст;
- один и тот же материал перепечатан без редакционной обработки.

Одно событие может быть представлено несколькими текстами только при различии фрейма, жанра, источника или региональной перспективы.

## 4. Проверка когнитивной насыщенности

Материал считается пригодным, если в нем можно выделить минимум три элемента из списка:

- концепт;
- фрейм;
- субъектная роль;
- модель действия;
- модель нормы;
- модель угрозы;
- ценностная оппозиция;
- культурная отсылка;
- литературная отсылка.

## 5. Проверка спорной разметки

Материал направляется на экспертную проверку, если:

- невозможно определить основной фрейм;
- концепты выделены слишком широко;
- разметка содержит больше 7 элементов в категории;
- есть конфликт между жанром и сегментом;
- материал имеет сомнительный правовой статус;
- материал содержит несколько равнозначных интерпретационных паттернов.
