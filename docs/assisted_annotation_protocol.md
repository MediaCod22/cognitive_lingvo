# Протокол использования ИИ при когнитивной разметке

Этот документ является единственным разделом проекта, где допускается прямое упоминание ИИ. В названиях файлов, метаданных корпуса, комментариях к данным и полях карточек такие упоминания не используются, если сам медиатекст не требует этого как предмета анализа.

## 1. Роль ИИ

ИИ может использоваться только как вспомогательный инструмент предварительной когнитивно-лингвистической разметки. Он не заменяет эксперта и не принимает финальное решение о включении материала в корпус.

## 2. Разрешенные задачи

ИИ может помогать:

- выделять предварительные концепты;
- предлагать возможные фреймы;
- находить метафоры;
- формулировать ценностные оппозиции;
- определять субъектные роли;
- предлагать модель действия, нормы или угрозы;
- выявлять культурные и литературные отсылки;
- приводить разметку к JSON-формату.

## 3. Запрещенные задачи

ИИ не должен:

- самостоятельно принимать решение о включении материала в корпус;
- заполнять карточку без проверки человеком;
- добавлять факты, которых нет в тексте;
- расширять текст за счет предположений;
- выдумывать источники, авторов, даты или URL;
- определять правовой статус источника без экспертной проверки;
- создавать финальную разметку без ручного контроля.

## 4. Принцип человек-в-контуре

Каждая разметка, созданная с помощью ИИ, получает статус assisted_draft. Статус reviewed присваивается только после проверки человеком.

Допустимые статусы:

- manual_draft;
- assisted_draft;
- expert_reviewed;
- revised;
- excluded.

## 5. Базовый промт

Используй следующий шаблон:

"Проанализируй медиатекст как материал для когнитивно-лингвистической разметки. Не оценивай политическую или фактическую позицию текста. Выдели только те элементы, которые явно выражены в тексте или надежно выводятся из его языковой структуры. Для каждой категории укажи не более 7 элементов. Если элементов больше, выбери главный, до трех вторичных и до трех дополнительных. Верни результат в JSON. Не добавляй внешних фактов."

## 6. Проверка результата

Эксперт обязан проверить:

- есть ли каждый элемент в тексте;
- не добавлены ли внешние смыслы;
- не превышен ли лимит 7 элементов;
- не смешаны ли концепт, фрейм и метафора;
- корректно ли выделена субъектная роль;
- не содержит ли разметка оценочных ярлыков;
- соответствует ли JSON схеме.

## 7. Принцип прозрачности

Если карточка была предварительно размечена с помощью ИИ, это фиксируется только в поле annotation_status со значением assisted_draft. В публичных метаданных не указывается название конкретного инструмента.
