# Методика отбора источников: подход PRISMA

## Концепт ПРИЗМА

Методика отбора источников в настоящем корпусе основана на адаптированном подходе PRISMA (Preferred Reporting Items for Systematic Reviews and Meta-Analyses), модифицированном для задачи формирования медиакультурного корпуса.

## Этапы отбора

### Этап 1: Идентификация (Identification)

**Целевой пул: 1400+ материалов**

На этапе идентификации осуществлялся систематический поиск медиаматериалов по следующим параметрам:

- **Источники**: 40+ русскоязычных медиаресурсов (федеральные, аналитические, культурные, региональные, научно-популярные)
- **Период**: 2023–2026 гг.
- **Язык**: русский
- **Формат**: текстовые публикации (статьи, интервью, колонки, рецензии, эссе)
- **Тематика**: 12 обязательных тематических зон (государство, технологии, образование, экономика, семья, безопасность, культура, международная повестка, региональное развитие, повседневность, литература, будущее)

Поисковые запросы формулировались для каждой тематической зоны и каждого раздела корпуса отдельно.

### Этап 2: Скрининг (Screening)

**Отобрано: 1200 материалов**

Из пула идентифицированных материалов проводился скрининг по критериям включения/исключения:

**Критерии включения:**
- Публикация в зарегистрированном или авторитетном медиаресурсе
- Наличие чёткой тематической принадлежности к одной из 12 обязательных зон
- Объём, достаточный для когнитивной аннотации (не менее 500 знаков)
- Публикация в 2023–2026 гг.
- Доступность URL на момент включения

**Критерии исключения:**
- Дублирование (одна и та же новость из разных источников)
- Недоступный или неработающий URL
- Чисто рекламный контент без аналитической или культурной ценности
- Агрегированные ленты без авторской позиции
- Материалы на иностранных языках

### Этап 3: Проверка на соответствие (Eligibility)

**Проверено: 1050 материалов**

Каждый материал из скрининговой выборки проверялся на соответствие дополнительным критериям:

1. **Когнитивная насыщенность** — материал содержит выраженные концепты, фреймы или метафоры, поддающиеся когнитивно-лингвистической аннотации
2. **Жанровая репрезентативность** — материал типичен для своего жанра и не является выбросом
3. **Источник** — материал опубликован в источнике, включённом в реестр доверенных медиа
4. **Баланс** — включение материала не нарушает тематический и жанровый баланс корпуса

### Этап 4: Включение (Included)

**Итоговый корпус: 1000 материалов**

Финальная выборка формировалась с учётом пропорций:

| Раздел корпуса | Целевая доля | Фактическое количество |
|---------------|-------------|----------------------|
| Новости | 20% | 200 |
| Аналитика | 15% | 150 |
| Интервью | 10% | 100 |
| Колонки / публицистика | 10% | 100 |
| Культурная журналистика | 15% | 150 |
| Научно-популярные тексты | 10% | 100 |
| Региональные медиа | 10% | 100 |
| Литературный канон | 10% | 100 |
| **Итого** | **100%** | **1000** |

## Схема отбора

```
Идентификация (1400+) → Скрининг (1200) → Проверка (1050) → Включение (1000)
     ↓                      ↓                   ↓                 ↓
  Поиск по            Критерии           Когнитивная       Финальный
  источникам и         включения/         насыщенность      корпус с
  тематикам           исключения         и баланс           разметкой
```

## Документирование

Каждый этап отбора документирован. Решения об исключении материалов на этапе скрининга и проверки фиксируются с указанием причины.

## Воспроизводимость

Методика ПРИЗМА обеспечивает воспроизводимость: исследователь, следуя тем же критериям и процедурам, должен получить сопоставимую выборку. Отклонения в конкретных URL-адресах допустимы (медиа-контент обновляется), но жанрово-тематическая структура должна сохраняться.
