# Промт предварительной когнитивной разметки

Этот промт относится к протоколу вспомогательной разметки и должен использоваться только вместе с экспертной проверкой.

## Шаблон

Проанализируй медиатекст как материал для когнитивно-лингвистической разметки.

Правила:

1. Не оценивай позицию автора.
2. Не добавляй внешних фактов.
3. Не выдумывай источники, даты, авторов и ссылки.
4. Выделяй только то, что выражено в тексте или надежно выводится из его языковой структуры.
5. В каждой множественной категории укажи не более 7 элементов.
6. Если элементов больше 7, выбери: 1 главный, до 3 вторичных, до 3 дополнительных.
7. Верни результат в JSON по схеме корпуса.
8. Если категория не выявляется, верни пустой массив или null.

Поля:

- concepts;
- frames;
- metaphors;
- value_oppositions;
- subject_roles;
- action_model;
- norm_model;
- threat_model;
- temporality;
- cultural_references;
- literary_references;
- world_model_dimension;
- uncertainty_notes.
